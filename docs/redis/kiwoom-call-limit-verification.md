# 키움 호출 제한 공식 확인 — 2026-10-12

## 추가 FAQ 근거와 최종 적용

사용자가 [공식 자주 묻는 질문](https://openapi.kiwoom.com/board/Board0301View?dummyVal=0)의 답변을 제공했다. 해당 답변은 실전 REST가 TR당·토큰별 초당 5건이고 모의투자는 초당 1건이며, 여러 토큰은 각각 한도를 가진다고 명시한다. 이에 따라 현재 단일 계좌/토큰의 각 api-id에 최근 1초 최대 5회 호출 시작을 허용하고 초과 요청만 기다리는 방식으로 변경했다. HTTP 응답 대기는 제한 장치를 잠그지 않는다. 실패·8005 재시도도 각각 횟수를 사용한다.

사용 안내 요약의 조회 그룹 합산 해석은 이 구체적인 FAQ 답변으로 대체한다. 아래는 FAQ 답변을 받기 전 조사 기록이다. 최근 1초 구간은 사용자에게 설명하고 승인받은 구현 기준이며 FAQ가 정확한 서버 시간 구간 방식까지 명시한 것은 아니다. 모의투자를 지원할 때는 별도 초당 1회 설정이 필요하다. 현재 운영 외부 주소는 실전 서버다.

후속 사용자 승인으로 담당의 호출 순서 대기를 최대 3초로 제한했다. 이는 프로젝트의 과부하 처리 정책이며 키움 FAQ의 요구 사항이 아니다. 3초가 지나면 키움 호출 전에 실패한다. HTTP 연결 3초·응답 5초는 유지하며 토큰 확보·외부 응답까지 포함한 전체 5초 완료를 보장하지 않는다.

## FAQ 답변 이전 조사 기록

출처: [키움 REST API 공식 소개 및 사용 안내](https://openapi.kiwoom.com/intro?dummyVal=0)의 API 호출 횟수 제한 표.

국내주식은 계좌별(토큰별) 주문 TR 초당 5회, 조회 TR 초당 5회로 안내한다. 개별 조회 api-id마다 초당 5회라는 문구는 없으며 조회 그룹 전체 합산이라는 문구도 명시되어 있지 않다. **공개 안내 문구만으로 실전 api-id별 한도와 조회 그룹 합산 한도 중 어느 쪽인지 확정하지 못했다.** 앞서 개별 TR당 5회라고 단정한 설명과 이를 합산 제한이라고 단정한 설명 모두 확정 근거가 부족하다. 모의투자는 별도로 계좌/토큰별 개별 TR 초당 1회가 명시되어 있다.

현재 운영 코드의 TR별 응답 완료 후 220ms 제한은 조회 그룹 전체의 합산 제한을 보장하지 않는다. 이전 개별 TR별 제한 구현과 로컬 두 TR 병렬 측정의 결과를 실제 키움의 허용 처리량으로 해석하면 안 된다. 해당 측정은 실제 키움에 요청하지 않았다.

사용자가 승인한 새 방식은 최근 1초의 호출 시작 횟수를 세고 초과 요청만 기다리는 방식이다. 사용자는 합산 범위를 바로 변경하는 대신 개별 TR 한도의 근거를 추가 확인하도록 선택했다. 범위가 확인되지 않아 아직 운영 코드를 변경하지 않았다. 현재 허용된 외부 TR 세 개는 모두 국내주식 조회다. 토큰 발급·웹소켓 메시지를 이 조회 TR 카운터에 임의로 포함하지 않는다.

제한 범위가 확정되면 실패·토큰 재시도도 실제 외부 요청마다 횟수에 포함하고, HTTP 응답을 기다리는 동안 제한 장치를 잠그지 않도록 구현한다. 연결 3초·응답 5초는 유지하며 대기 상한은 별도 미확정 정책이다.

## 추가 조사 결과

- 공식 사이트의 공개 안내·검색 결과에서는 실전의 api-id별 또는 조회 그룹 합산을 명시한 추가 근거를 찾지 못했다. 검색에서 찾지 못한 사실이 그 규칙의 부재를 증명하는 것은 아니다.
- [키움 공식 클라이언트 코드](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/kiwoom/core/client.py)를 확인했다. 일반 요청 메서드에는 한도 분류·호출 횟수 제한기가 없고 연속 조회에 기본 0.2초 간격을 둔다. 이 코드는 실전 한도 범위를 확정하는 근거가 아니다.
- 공개 FAQ를 브라우저에서 확인하려 했으나 공식 사이트가 `CD-14005` 오류 페이지를 반환했다. 해당 환경에서 FAQ 내용을 열람하지 못했다.
- 실전 API에 한도를 초과하는 요청을 보내 실험하지 않았다. 확인되지 않은 실제 요청 실패로 공식 운영 규칙을 추측하지 않는다.

## 문의 문안 — 아직 발송하지 않음

> 국내주식 실전 REST API에서 같은 계좌/토큰으로 ka10001을 초당 4회, ka10100을 초당 4회 호출하여 조회 요청 합계가 초당 8회가 되면 허용되나요? 초당 5회가 개별 api-id별 제한인지 조회 TR 전체 합산 제한인지 확인 부탁드립니다. 개별 제한 외에 조회 그룹 전체 제한이 함께 있나요? 1초는 고정 구간인지 최근 1초 구간인지, 5건의 동시 요청은 허용되는지도 확인 부탁드립니다. 모의투자의 개별 TR 초당 1회 규칙과 구분하여 답변 부탁드립니다.
