# Swagger 적용 계획

사용자가 대화에서 승인한 7단계 계획을 현재 feat/219-swagger에서 실행한다.

목표: 기존 API 동작을 유지하며 OpenAPI 문서·한국어 설명·쿠키/CSRF 기반 Try it out을 제공한다.
설계: springdoc 3.2.0과 Swagger UI를 사용한다. HttpOnly CSRF 쿠키를 유지하고 API가 반환한 masked token을 요청 헤더로 사용한다.
대안: 기본 쿠키 읽기 CSRF 기능은 HttpOnly 쿠키에 맞지 않아 기존 CSRF API 호출로 대체한다. Bearer 입력 방식은 기존 쿠키 인증과 맞지 않아 사용하지 않는다.

- [x] 기존 Controller/DTO/보안과 API 명세 시트 대조
- [x] 문서 공개·기존 API 보호 통합 테스트 작성 및 미적용 실패 확인
- [x] 의존성, GET 문서 경로 허용, 기본 문서·태그·주요 예시 추가
- [x] HttpOnly 쿠키용 CSRF interceptor 구현 및 JavaScript 테스트
- [x] 문서 비활성화, 인증·CSRF와 주요 Controller 회귀 테스트 검증
- [x] 변경 검토와 검증 결과 기록

검증 명령과 명세 차이는 docs/swagger.md 참고.

검증 결과: Java 69개·JavaScript 3개 통과, bootJar·spotbugsMain 성공, git diff --check 통과.
