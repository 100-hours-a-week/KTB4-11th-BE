# AI 대결 SENT 시작 정책 변경

## 승인된 요구사항

사용자가 파일별 계획을 확인한 뒤 "진행, 설명(해설)"으로 승인했다. 최신 dev에서 분기한 codex/ai-start-on-sent에서 진행한다.

- AI 준비 완료 콜백 대신 해당 대결의 Outbox SENT를 자동 시작 조건으로 사용한다.
- 장 시간, 실제 거래 종료, 기존 사용자 vs AI 정책과 대결 잠금은 유지한다.
- 콜백 API·인증 규칙·준비 완료 시각 매핑을 제거한다. 실제 DB 컬럼은 유지하므로 새 스키마 적용은 없다.
- AI 파트에 완료 콜백 불필요와 미설정 계좌 노출 가능성을 배포 전에 공유해야 한다. 이 사실은 코드 수정 전 사용자에게 안내했다. 팀원에게 직접 메시지는 보내지 않는다.
- 기존 READY+SENT는 기간 내 시작 대상이다. 전송 기록 없음·PENDING·CANCELLED·기간 만료는 자동 복구하거나 수동 변경하지 않는다.
